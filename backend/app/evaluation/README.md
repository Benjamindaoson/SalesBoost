# SalesBoost Agent Evaluation

This module upgrades SalesBoost from a feature-oriented AI application into an evaluated autonomous agent system.

## Evaluation dimensions

- Intent classification
- Sales stage transition
- Tool selection
- Memory consistency
- Failure recovery
- Grounded response quality

## Planned structure

```
evaluation/
├── scenarios/       # golden sales conversations
├── runners/         # execute agent trajectories
├── metrics/         # scoring functions
├── reports/         # evaluation reports
└── recovery/        # failure taxonomy
```
