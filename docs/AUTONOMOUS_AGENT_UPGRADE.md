# Autonomous Sales Agent Upgrade

## Goal

Evolve SalesBoost from an AI sales platform into a reliable autonomous sales agent runtime.

## Upgrade Tracks

### 1. Evaluation Harness

- Golden sales scenarios
- Intent accuracy
- Stage transition accuracy
- Tool selection accuracy
- Recovery success rate

### 2. Reliability Layer

- Failure taxonomy
- Recovery policies
- Replanning
- Human escalation

### 3. Memory Evaluation

Validate:

- memory write
- memory retrieval
- stale memory handling
- belief updates

### 4. Runtime Consolidation

Converge multiple historical agent implementations into a unified lifecycle:

Request -> Plan -> Execute -> Observe -> Recover -> Evaluate
