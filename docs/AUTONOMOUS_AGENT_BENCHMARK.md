# Autonomous Sales Agent Benchmark

## Evaluation Dimensions

- Intent classification
- Sales stage transition
- Tool selection
- Grounded response
- Memory consistency
- Failure recovery

## Golden Scenarios

The benchmark covers:

1. Customer objection handling
2. Requirement discovery
3. Buying signal detection
4. Recovery after tool failure
5. Memory update correctness

The goal is to measure agent reliability rather than only response quality.
